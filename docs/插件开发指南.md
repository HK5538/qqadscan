# 插件开发指南

插件让你在不改动主程序的前提下扩展识别能力：加映射、加关键词、按行加分/减分、
往报告里写备注。插件出问题会被单独捕获，不会影响整次扫描。

## 1. 目录结构

```
plugins/
  my_rule/
    plugin.json     清单（可省略，省略时默认找 plugin.py）
    plugin.py       入口，必须有 PluginBase 子类或 PLUGIN 实例
    helper.py       可选，同目录的模块可以用相对/绝对 import
```

也支持单文件插件：`plugins/my_rule.py`。

`plugin.json`：

```json
{
  "name": "my_rule",
  "version": "1.0.0",
  "entry": "plugin.py",
  "class": "MyPlugin",
  "enabled": true,
  "author": "your name",
  "description": "一句话说明"
}
```

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `name` | 否 | 插件名，默认取类里的 `name`；用于在 `plugins.disabled` 里禁用 |
| `entry` | 否 | 入口文件，默认 `plugin.py` |
| `class` | 否 | 类名；不写则依次找模块里的 `PLUGIN` 实例、`Plugin` 类 |
| `enabled` | 否 | `false` 时不加载 |

## 2. 最小例子

```python
from qqadscan.plugins.api import PluginBase, ScoreDelta

class MyPlugin(PluginBase):
    name = "my_rule"
    version = "1.0.0"
    description = "出现「上车」时加分"

    def adjust_score(self, candidate, analysis, ctx):
        if "上车" in candidate.text:
            return [ScoreDelta(6, "上车暗语", "常见引流黑话")]
        return []

PLUGIN = MyPlugin()
```

## 3. 生命周期

```
加载 → setup(ctx)
扫描前 → on_lexicon_ready(ctx)      ← 可以往词库里加映射/关键词
每一行 → before_line(line, ctx)     ← 返回新文本；返回 None 跳过该行
        ↓ 解码
        after_decode(candidates, ctx)
        ↓ 逐条评分
        adjust_score(candidate, analysis, ctx)
扫描结束 → teardown(ctx)
```

## 4. API

### PluginContext

| 属性/方法 | 说明 |
| --- | --- |
| `ctx.config` | 只读配置对象，`ctx.config.get("score", "group_window")` |
| `ctx.lexicon` | 词库，可 `add_digit / add_keyword / add_ad_keyword / add_noise / add_quantifier` |
| `ctx.root` | 程序数据目录 |
| `ctx.logger` | 标准 logging 对象 |
| `ctx.note(text)` | 往报告头部的「插件说明」里加一行 |
| `ctx.data` | 插件自己的字典，跨回调保存状态 |

### ScoreDelta

```python
ScoreDelta(delta=6, label="上车暗语", detail="常见引流黑话")
```

`delta` 为正加分、为负减分；`label` 会出现在详情面板和报告的「评分明细」里。

### Candidate

| 属性 | 说明 |
| --- | --- |
| `text` | 当前行文本（可能已被 `before_line` 改过） |
| `span` | 号码在 `text` 中的 `(start, end)` |
| `raw` | 号码原文 |
| `digits` | 还原出的数字串 |
| `atoms` | 每个数字原子的 `start/end/digit/token/kind/weight` |
| `kinds` | 各类伪装出现次数，如 `{"symbol": 3, "homophone": 2}` |
| `obfuscation` | 混淆度 0–1 |
| `noise` / `noise_count` | 号码中间夹的噪音字符 |
| `plain_ascii` / `plain_cjk` | 是否纯数字/纯中文数字 |
| `numeric_value` | 中文数字换算后的值（如「一百二十三」→123） |
| `decode_steps()` | 逐段解码说明（字符串列表） |

### KeywordAnalysis

| 属性 | 说明 |
| --- | --- |
| `group_hits` / `ad_hits` | `KeywordHit(keyword, start, end, distance)` 列表 |
| `best_group` | 权重×距离最优的群关键词 |
| `group_strength` / `ad_strength` | 0–1.5 的综合强度 |
| `group_tokens` / `ad_tokens` | 去重后的词列表 |
| `has_group_evidence` | 是否有「权重≥0.7 且距离≤6」的群关键词 |

## 5. 三个实用例子

### 往词库补充写法

```python
def on_lexicon_ready(self, ctx):
    for token in ("飞机群", "电报群"):
        ctx.lexicon.add_keyword(token, 0.9, note="由插件注册")
    # 也可以加数字映射：ctx.lexicon.add_digit("㊫", 7, "symbol", 0.9)
```

### 按上下文减分

```python
def adjust_score(self, candidate, analysis, ctx):
    head = candidate.text[max(0, candidate.start - 12):candidate.start]
    if head.rstrip().endswith(("订单号", "ID", "编号")):
        return [ScoreDelta(-15, "像编号", "号码前面是订单号/ID")]
    return []
```

### 跨行统计（用 ctx.data）

```python
def setup(self, ctx):
    ctx.data["seen"] = {}

def adjust_score(self, candidate, analysis, ctx):
    seen = ctx.data["seen"]
    count = seen.get(candidate.digits, 0)
    seen[candidate.digits] = count + 1
    if count >= 2:
        return [ScoreDelta(4, "重复出现", f"同一号码第 {count + 1} 次出现")]
    return []
```

## 6. 调试

- 插件加载失败不影响主程序，错误会写进报告头部的「插件问题」；
- 想看详细信息，用 `python -m qqadscan scan 目录 -v`，日志会打到 stderr；
- 改完插件重开程序（或重新扫描）即可，插件在每次扫描开始时重新加载。

## 7. 兼容性

- `PluginBase.api_version` 目前是 `"1"`，与程序不一致的插件会被跳过并记录原因；
- 未来的钩子只增不改，老插件在新版本里仍然可用；
- 请不要在插件里做联网、删除文件等操作——这个程序的定位是「只看不动」。
