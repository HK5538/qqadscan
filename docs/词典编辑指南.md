# 词典编辑指南

词库是这套工具的核心：它决定「什么写法算数字」。所有词库都是 UTF-8 的 TSV
（Tab 分隔），用记事本、VS Code、Excel 都能改，保存后点界面上的
「重新载入配置与词库」即可生效。

## 1. 文件与加载顺序

`lexicon/` 下按文件名排序加载，**后面的覆盖前面的**：

```
00_digits_base.tsv        半角数字、中文数字、大写数字
10_digits_homophone.tsv   同音/谐音汉字
20_digits_symbol.tsv      圈号、括号号、全角、上下标、罗马数字（脚本生成）
30_digits_shape.tsv       形状相近的特殊符号
40_digits_pinyin.tsv      拼音（含声调、带数字声调）
50_digits_radical.tsv     偏旁部首
60_noise.tsv              噪音字符
70_group_keywords.tsv     群关键词
80_ad_keywords.tsv        广告/引流关键词
90_quantifiers.tsv        量词
95_time_words.tsv         时间词
```

想让自己写的东西优先级最高，就新建 `99_my.tsv`。

## 2. 六个字段

```
token	category	value	kind	weight	note
```

| 字段 | 说明 |
| --- | --- |
| `token` | 要识别的字符串。可以是一个字符（`氿`），也可以是多个（`jiu`、`q群`、`0️⃣`） |
| `category` | `digit` / `noise` / `group_keyword` / `ad_keyword` / `quantifier` / `time_word` |
| `value` | 仅 `digit` 用，填 0–9 |
| `kind` | 仅 `digit` 用，见下表 |
| `weight` | 0–2 的可信度，参与「伪装程度」评分 |
| `note` | 备注，只用于展示 |

### kind 取值

| kind | 含义 | 例子 |
| --- | --- | --- |
| `ascii` | 半角数字 | `7` |
| `cjk` | 中文数字 | `七`、`两` |
| `cjk_formal` | 大写中文数字 | `柒`、`叁` |
| `homophone` | 同音/谐音字 | `期`→7、`寺`→4 |
| `symbol` | 圈号类符号 | `⑦`、`㈦`、`７` |
| `shape` | 形状相近符号 | `∈`→3、`亖`→4 |
| `pinyin` | 拼音（自动要求词边界） | `qi`、`qī` |
| `radical` | 偏旁部首 | `彡`→3 |

`homophone / symbol / shape / pinyin / radical` 会参与「伪装程度」加分；
`ascii / cjk / cjk_formal` 视为「直白写法」，不额外加分，但会被「纯数字」规则判断。

## 3. 常见操作

### 加一个符号映射

`lexicon/99_my.tsv`：

```
token	category	value	kind	weight	note
㊫	digit	7	symbol	0.9	我遇到的写法
```

### 加一个同音字

```
氿	digit	9	homophone	0.85	jiǔ
```

权重建议：

| 情况 | 权重 |
| --- | --- |
| 完全同音、日常几乎不用 | 0.8–0.9 |
| 声调不同但很像 | 0.6–0.75 |
| 只是形近/方言相近 | 0.4–0.6 |

### 删除一个映射

任意词库文件里加一行，`token` 前面加 `!`：

```
!思	digit
```

### 覆盖权重

在排序靠后的文件里重写一遍同名词条即可（后加载的覆盖前面的）：

```
思	digit	4	homophone	0.30	这个字太常见，压低权重
```

### 加群关键词

```
裙裙	group_keyword			0.9	叠字写法
```

权重 ≥ 0.7 且距离号码 ≤ 6 字时，会被当作「有群证据」，让纯数字规则放行。

### 加量词

```
刀	quantifier			0.6	价格黑话（一刀=100元）
```

## 4. 三条容易踩的坑

1. **噪音优先**。`config.json` 里 `decode.noise_precedence` 默认是 `true`：
   一个字符如果同时在 `noise` 和 `digit` 里，会被当成噪音跳过。
   例如把 `〇` 放进噪音表，它就再也不会被识别成 0。
2. **拼音有词边界**。`san` 不会命中 `sans-serif`，这是故意的。
   如果你想让某个拼音在词中间也生效，把它改成 `homophone` 类型即可。
3. **别把普通汉字当数字**。`的`、`是`、`有` 这类高频字如果映射成数字，
   正常聊天会产生大量「候选号码」。不得已要加，权重压到 0.3 以下，并确保
   最少位数（`decode.min_digits`）不要太低。

## 5. 调试

```bat
:: 看看一句话能解出什么
python -m qqadscan decode "㈡〔〔氿▲4⊥〖婈４□（叁5〓>⒍思蒐←索≌q羣："

:: 看看词库现在有多少条、某条在不在
python -m qqadscan lexicon --dump | findstr 氿
```

`decode` 会打印逐字解码过程、命中的关键词、以及每一分的来源，改词库时非常有用。

## 6. 建议

- 改之前先复制一份 `lexicon` 目录，或者用 git 管理；
- 一次只改一类，改完用 `samples/demo.txt` 扫一遍，确认正常聊天仍然不报警；
- 词库没有「标准答案」，按你实际遇到的语料迭代就行。
